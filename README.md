# ResumeAI

## *Overview*  
The Resume Analyzer Chatbot is an AI-powered tool designed to assist job seekers by analyzing their resumes against job descriptions. It extracts key details, suggests resume improvements, generates personalized cover letters, and calculates a job fit score. This tool uses Google Gemini AI for natural language processing (NLP) to enhance the hiring process.

## *Key Findings*  
- **AI Resume Analysis**: Effectively extracts personal information, education, skills, and work experience from resumes.
- **Cover Letter Generation**: Generates tailored cover letters based on the job description.
- **Fit Score Calculation**: Provides a compatibility percentage indicating how well the resume matches the job requirements.
- **Actionable Insights**: Recommends areas for improvement in the resume based on job description alignment.

## *Files*  
- **ResumeAnalyzerChatbot.ipynb**: Jupyter notebook with the full implementation, including code for resume analysis, fit score calculation, and cover letter generation.
- **Readme.pdf**: Overview and setup instructions for using the chatbot.
